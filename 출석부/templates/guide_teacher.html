담당자 사용 가이드

담당자 계정으로 로그인 시에만 확인 가능한 페이지입니다.

1. 로그인

  1. 관리자에게 받은 아이디와 비밀번호로 로그인합니다
  2. 로그인 후 자신에게 배정된 반의 학생만 확인/관리할 수 있습니다
  3. 비밀번호 변경이 필요하면 관리자에게 요청하세요

2. 학생 등록 방법

경로: 상단 메뉴 > 학생 관리

  1. 지점 선택 > 반 선택 > 학생 이름 입력
  2. 등록 유형을 선택하세요:
    • 추가 : 단순 추가 (기존 재원생을 시스템에 처음 등록할 때)
    • 등록 : 신규 등록 (새로 원에 등록한 학생. 결산서에 +1 반영)
    • 재등록 : 휴원 복귀 (휴원했다가 돌아온 학생. 결산서에 +1 반영)
참고: 수학+영어 두 과목을 듣는 학생은 각 반에 각각 등록해 주세요.
원비명부에서 자동으로 과목별 금액이 합산됩니다.

3. 반 정보 수정

경로: 상단 메뉴 > 학생 관리 > 상단 "반 정보 수정" 섹션

  • 자신에게 배정된 반의 과목, 학년, 반 이름, 요일을 수정할 수 있습니다
  • 수정 후 수정 버튼 클릭

4. 학생 상세 기록 방법

경로: 학생 관리 > 학생 이름 옆 상세 클릭

인적사항

  • 등록일: 학생의 원 등록일
  • 전화번호: 학생 본인 / 학부모 전화번호
  • 등원 요일: 예) 월,수 또는 화,목
  • 특이사항: 학생에 대한 메모
  • 원비 설정: 수강료, 교재비, 기타, 특강비, 할인율 입력
  • 형제 설정: 형제 학생 선택 시 할인율 자동 5% 적용

입력 후 인적사항 저장 클릭

성적 관리

시험 유형입력 항목그래프
중간고사 / 기말고사 연도, 학기, 과목, 예상/목표/실제 점수, 등급 내신시험 성적추이 그래프
모의고사 (고3만) 연도, 월, 예상/목표/실제 점수, 등급 모의고사 성적추이 그래프
월말평가 연도, 월, 점수 월말평가 성적추이 그래프

학부모 상담보고서

  • 연도/월 선택 > 상담 내용 작성 > 상담보고서 등록
  • 매월 학부모 상담 후 기록을 남기세요

5. 출석부 작성

경로: 상단 메뉴 > 출석부

  1. 담당자 선택 (본인 선택 또는 전체)
  2. 날짜 선택 (기본: 오늘)
  3. 지점 선택
  4. 과목(반) 선택
  5. 학생별로 입력:
    • 출석: 정상등원 / 지각 / 결석
    • 사유: 지각/결석 사유 (선택)
    • 숙제: 완료 / 미완료
    • 미완료 대책: 숙제 미완료 시 대책 기록
  6. 저장 클릭

6. 수업계획서 작성

경로: 상단 메뉴 > 수업계획서

  1. 지점 > 반 선택
  2. 날짜 선택 > 수업내용 입력 > 숙제 입력
  3. 등록 클릭
  4. 등록된 계획서에서 카카오 공지 버튼으로 학부모 안내 메시지 복사 가능

7. 원비명부

경로: 상단 메뉴 > 원비명부

  • 학생 상세에서 설정한 수강료/교재비가 자동으로 표시됩니다
  • 여러 과목 수강 학생은 과목별 행 + 합계 행이 표시됩니다
  • 결제처리 스위치를 ON으로 전환하면 결제 완료 처리됩니다
  • 비고란에 메모를 남길 수 있습니다

8. 통계 확인

  • 학생별 통계: 지점 > 반 > 학생 > 연도/월 선택 > 출석률, 숙제 완료율, 주간별 추이 확인
  • 반 별 통계: 지점 > 반 선택 > 월간 요약, 캘린더형 일별 현황, 상세 목록 확인
  • 각 통계 페이지에서 담당자 이름이 표시됩니다

9. 학생 휴원 및 삭제

경로: 학생 관리 페이지

  • 휴원 : 학생을 휴원 처리합니다. 결산서에 -1 반영. 기록은 보존됩니다.
  • 재등록 : 휴원 학생을 복귀시킵니다. 결산서에 +1 반영.
  • 삭제 : 학생을 완전히 삭제합니다. 모든 출석/성적 기록이 함께 삭제되므로 주의하세요!

10. 교육과정 등록

경로: 상단 메뉴 > 교육과정

  • 과목/학년/대단원/소단원을 등록하면 수업계획서 작성 시 활용 가능
  • 본인이 등록한 교육과정만 삭제 가능합니다
