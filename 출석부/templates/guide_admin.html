관리자 사용 가이드

관리자 계정으로 로그인 시에만 확인 가능한 페이지입니다.

1. 지점 및 반 관리

경로: 상단 메뉴 > 관리

지점 추가/수정/삭제

  1. 관리 페이지 상단 "지점 관리" 섹션에서 지점 이름을 입력하고 추가 클릭
  2. 기존 지점 이름을 수정하려면 입력란에서 직접 수정 후 수정 클릭
  3. 지점 삭제 시 해당 지점의 학생 기록은 보존됩니다 (지점만 해제)

반 추가/수정

  1. 지점 선택 > 과목 선택 > 학년 입력 > 반 이름 입력 > 요일 입력 > 추가
  2. 기존 반의 과목, 학년, 반, 요일을 모두 수정할 수 있습니다
  3. 반 삭제 시 해당 반의 학생 기록은 보존됩니다

2. 학생 등록 방법

경로: 상단 메뉴 > 관리 > 재원 학생 관리 섹션

  1. 지점 선택 > 반 선택 > 학생 이름 입력
  2. 등록 유형 선택:
    • 추가 : 단순 추가 (결산서에 영향 없음, 월초인원에 반영)
    • 등록 : 신규 등록 (결산서 순증 +1)
    • 재등록 : 휴원 복귀 (결산서 순증 +1)
중요: 수학+영어 두 과목을 듣는 학생은 각 반에 각각 등록해야 합니다.
원비명부에서 자동으로 과목별 금액이 합산되어 표시됩니다.

3. 학생 상세 기록 방법

경로: 관리 > 학생 목록에서 상세 클릭

인적사항

  • 등록일, 전화번호, 학부모 전화번호, 등원 요일, 특이사항 입력
  • 센터/반 변경: 관리자만 가능. 지점과 반을 변경하여 학생 이동
  • 원비 설정: 수강료, 교재비, 기타, 특강비, 할인율 입력 > 원비명부에 자동 반영
  • 형제 설정: 형제 학생 선택 시 할인율 자동 5% 적용 (수정 가능)

성적 관리

  • 내신시험: 연도/학기/시험유형(중간/기말) 선택 > 예상/목표/실제 점수 + 등급 입력
  • 모의고사: 고3 학생만 표시. 월 선택 후 점수 입력
  • 월말평가: 연도/월 선택 > 점수 입력. 별도 성적추이 그래프로 확인 가능

변경이력

  • 관리자만 이력 추가/삭제 가능
  • 유형: 단순추가 / 등록(+1) / 휴원(-1) / 재등록(+1)
  • 결산서 자동 집계에 직접 반영됩니다

학부모 상담보고서

  • 연도/월 선택 > 상담 내용 작성 > 등록

4. 담당자 관리

경로: 상단 메뉴 > 담당자 관리

  1. 담당자 추가: 아이디/비밀번호/이름 입력 후 추가
  2. 반 배정: 담당자별로 담당할 반을 선택하여 배정. 여러 반 배정 가능
  3. 비밀번호 초기화: 담당자 비밀번호를 관리자가 변경 가능
  4. 관리자 계정 변경: 페이지 하단에서 관리자 아이디/비밀번호 변경

5. 출석부

경로: 상단 메뉴 > 출석부

  1. 담당자 > 날짜 > 지점 > 과목(반) 순서로 필터 선택
  2. 학생별 출석(정상등원/지각/결석), 사유, 숙제(완료/미완료), 미완료 대책 입력
  3. 저장 클릭으로 일괄 저장

6. 원비명부

경로: 상단 메뉴 > 원비명부

  • 학생 상세에서 설정한 수강료/교재비/기타/특강비/할인율이 자동 반영
  • 여러 과목 수강 학생은 과목별 행 + 합계 행이 표시됩니다
  • 결제처리 토글(스위치)로 결제 완료 처리. 결제일 자동 기록
  • 관리자는 전체 지점 매출 총액 및 지점별 매출 확인 가능
  • 이름 검색 시 전체 지점에서 검색 가능

7. 결산서

경로: 상단 메뉴 > 결산서

  • 자동 집계: 변경이력(추가/등록/재등록/휴원) 기반으로 자동 계산
  • 월초인원: 해당 월 이전까지 누적된 추가 학생 수 기준
  • 등록/재등록: 결산서에서 +1로 집계
  • 휴원: 결산서에서 -1로 집계
  • 반별 집계, 지점별 집계(중복 제거), 담당별 통계, 지점별 통계 확인 가능
  • 월별 / 분기별 / 연간 보기 전환 가능

8. 통계 및 보고서

  • 학생별 통계: 지점 > 반 > 학생 선택 후 출석/숙제 통계 확인. 담당자 정보 표시
  • 반 별 통계: 지점 > 반 선택 후 월간 요약, 캘린더형 일별 현황, 상세 목록 확인. 담당자 정보 표시
  • 보고서: 출석부/수업계획서/상담보고서/결산서를 PDF 출력 가능한 형식으로 조회

9. 수업계획서 및 교육과정

  • 수업계획서: 지점/반/날짜 선택 > 수업내용 + 숙제 입력. 카카오 공지 형식 복사 가능
  • 교육과정: 과목/학년/대단원/소단원 등록. 수업계획서 작성 시 연동 가능
